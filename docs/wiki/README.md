# Copia navegable de la documentación

Esta carpeta conserva una copia de lectura de la [Wiki publicada en GitHub](https://github.com/koldoaso/Reto01-Omni3/wiki). La Wiki tiene su propio repositorio Git, independiente del código del proyecto:

```bash
git clone https://github.com/koldoaso/Reto01-Omni3.wiki.git
```

El checkout local está en la carpeta hermana `Reto01-Omni3.wiki` y su copia de respaldo en `Reto01-Omni3.wiki.bundle`. La publicación incluye `Home`, nueve secciones, `_Sidebar` y `_Footer`; este README solo explica la copia y no se publica como página. Los enlaces entre páginas de la Wiki apuntan a sus URLs sin extensión `.md`.

Empieza en [Home](Home.md) y usa [_Sidebar](_Sidebar.md) para recorrer las nueve secciones. Los enlaces de esta copia llevan extensión `.md` para funcionar en el navegador de archivos de GitHub.
